## ПЕРВИЧНЫЙ ЗАПРОС (enterprise, под три входа как в вашем редакторе)

Создай приложение **DentReserve Pro** для стоматологии **DentLux** (премиальный сегмент).

**User Input (три поля):**
1. **Visitor Question** — вопрос посетителя (текст).
2. **Language** — `kk` или `ru` (если пусто или `kk` — весь ответ консультанта на **әдеби қазақ тілі**; если `ru` — на **русском**).
3. **Clinic Data Json** — JSON с врачами и услугами/ценами (аналог выгрузки из API: GET /api/doctors и GET /api/services проекта DentLux).

**Шаг Generate** (обязательно используй **@** для подстановки всех трёх входов в промпт):
- Стиль коммуникации — как у **топовых международных стоматологических клиник**: структурировано, тепло, профессионально, без «воды» и без панибратства.
- **Только факты из Clinic Data Json** — не выдумывай цены, ФИО, расписание.
- **Не ставь диагноз и не назначай лечение**; явно укажи, что очный осмотр при необходимости.
- При **острой боли, отёке, лихорадке, кровотечении изо рта, травме челюсти** — отдельный абзац: срочно к врачу или скорая помощь (103 / экстренные службы по региону).
- Лёгкий HTML для акцентов: **<b>**, *<i>*.

**Шаг Render / Output:**
- Сначала отобрази формулировку вопроса посетителя, затем полный ответ консультанта; удобочитаемый вид для конечного пользователя.

**Контекст разработки (внутренний):** бэкенд DentLux — Node.js, Express, Prisma, PostgreSQL; n8n и Jenkins используются для автоматизации и CI/CD.

После генерации при необходимости донастраивай шаги через поле **«Edit these steps»** — готовые фразы см. **deployment/n8n/opal-enterprise-prompts.txt**.
